## 学习方向

**编程基础与实践**：通过独立练习理解语言特性、输入输出、数据结构和错误处理；用小项目把知识串起来。

**课程学习与复习**：按课程归档课件与作业，把题目、参考解答和个人答案分开，便于回看与核对。

**AI 应用探索**：从可复现的虚构数据开始，关注数据切分、检索、生成效果与事实可靠性。研究原型的完成程度以项目说明为准。

## 如何使用这个导航

- 找代码或运行方法：进入对应仓库的 README。
- 找课程文件：从课程仓库的学期与课程目录进入。
- 继续学习：阅读编程仓库中的计划与进度记录，并核对实际源码。
- 反馈错误：在对应内容仓库提交问题，附上文件路径与具体说明。

本仓库只维护导航与学习方向；代码、资料更新和验证记录以各仓库为准。
