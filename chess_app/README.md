# 国际象棋对弈（ChessGame）

基于 **python-chess** 规则引擎 + **Tkinter** 界面的桌面国际象棋程序，已用 PyInstaller 打包为单文件 exe。

## 如何运行

- 直接双击 `dist\ChessGame.exe` 即可（首次启动需几秒自解压，无需安装 Python）。
- 从源码运行：`pip install python-chess` 后执行 `python chess_app.py`。
- 重新打包 exe：`pyinstaller --onefile --windowed --name ChessGame chess_app.py`。
- 重新生成棋子素材（需 Pillow）：`python make_assets.py`。

## 功能与规则

### 两种对弈模式
1. **双人对弈**：同一台电脑上两人轮流落子；执白方可选「玩家1执白 / 玩家2执白 / 系统随机分配」。
2. **人机对弈**：与内置 AI 对弈；你可选「我执白 / 我执黑 / 系统随机」，AI 难度分简单 / 中等 / 困难三档。
   - 你执黑时棋盘自动翻转（你的棋子在下方），并由执白的 AI 自动先行。

### 棋子皮肤 / 棋盘主题 / 音效
- **棋子皮肤**：立体经典（象牙/乌木渐变质感）、立体木纹（枫木/胡桃木）、经典字符（Unicode 平面字形），主菜单预设、对局中侧栏可实时切换。
- **棋盘主题**：经典绿、胡桃木、灰蓝、云石灰四套配色，可实时切换。
- **走子音效**（程序实时合成，无外部音频文件；可随时勾选开关）：
  选中轻响、普通走子木叩声、吃子闷响、王车易位双响、将军两连警示音、
  兵升变上行音、获胜琶音 / 失利下行音 / 和棋提示音。

### 胜率评估系统
- **胜率映射**：参考 Elo 逻辑，用 logistic 函数把引擎 centipawn 局面分
  映射为白方胜率：`胜率 = 100 / (1 + 10^(-cp/400))`。
  校准锚点：0 分=50%、+100≈64%（约 65%）、+300≈85%、-100≈36%；将杀截断为接近 0%/100%。
- **实时计算**：每走一步（含 AI 落子）即在后台线程以 2 层搜索评估当前局面，
  侧栏胜率条、双方胜率、局面分（如 +1.32 白优）即时更新，中局评估约 5~20 毫秒，
  不阻塞界面；人机模式另显示“你的胜率”。悔棋后胜率回退重算。
- **走法质量评价**：对比玩家走法与引擎最优走法的分差（centipawn loss），
  给出六档标签并标注在棋谱上：绝妙 !!（最优且建功/合理弃子）、最佳 !、好棋、
  普通、失误 ?!、大漏勺 ??；失误/漏招同时提示引擎首选走法与损失分值。

### 官方规则（全部由 python-chess 严格判定）
- 只允许走合法步；非法走法无法落下
- 将军提示、将杀判胜、逼和（无子可动且未被将军）判和
- 王车易位（长易位/短易位）、吃过路兵、兵到底线升变（后/车/象/马四选一弹窗）
- 子力不足自动和棋、五次重复局面与七十五回合自然限着自动和棋
- 三次重复局面、五十回合规则可点「提和」主张和棋；双人模式另支持协议和棋
- 「认输」结束对局；「悔棋」人机模式一次撤销双方两步、双人模式撤销一步

### 界面与操作
- 点击己方棋子选中（高亮合法落点：圆点=可移动，圆环=可吃子），再点目标格落子
- 右侧面板：行棋状态、双方损失棋子与子力对比、代数记谱棋谱（如 Nf3、O-O、exd5、Qh4#）
- 新对局 / 悔棋 / 提和 / 认输 / 返回主菜单；皮肤、主题、音效对局中即时切换

### AI 说明
内置 AI 为 Negamax + Alpha-Beta 剪枝搜索，结合子力价值与位置价值表：
- 简单：搜索 1 层，近优走法带随机性，适合新手
- 中等：搜索 2 层
- 困难：搜索 3 层（纯 Python 计算，复杂局面思考可能需数秒，属正常现象）

## 文件说明
- `chess_app.py`：主程序（界面 + AI）
- `chess_sfx.py`：走子音效实时合成与播放（Windows winsound）
- `piece_assets.py`：立体棋子 PNG 的内嵌资源（由 make_assets.py 生成）
- `make_assets.py`：立体棋子素材生成器（Pillow 程序化绘制）
- `assets/`：24 个棋子 PNG 与预览图
- `tests_logic.py`：规则与 AI 的无头逻辑测试（13 项）
- `smoke_gui.py`：界面自动化冒烟测试（皮肤/主题/落子/AI/换边）
- `dist\ChessGame.exe`：打包好的可执行程序
