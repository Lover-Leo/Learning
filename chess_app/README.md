# 国际象棋对弈（ChessGame）

基于 **python-chess** 规则引擎 + **Tkinter** 界面的桌面国际象棋程序，已用 PyInstaller 打包为单文件 exe。

## 如何运行

- 直接双击 `dist\ChessGame.exe` 即可（首次启动需几秒自解压，无需安装 Python）。
- 从源码运行：`pip install python-chess` 后执行 `python chess_app.py`。
- 重新打包 exe：`pyinstaller --onefile --windowed --name ChessGame chess_app.py`。

## 功能与规则

### 两种对弈模式
1. **双人对弈**：同一台电脑上两人轮流落子；执白方可选「玩家1执白 / 玩家2执白 / 系统随机分配」。
2. **人机对弈**：与内置 AI 对弈；你可选「我执白 / 我执黑 / 系统随机」，AI 难度分简单 / 中等 / 困难三档。
   - 你执黑时棋盘自动翻转（你的棋子在下方），并由执白的 AI 自动先行。

### 官方规则（全部由 python-chess 严格判定）
- 只允许走合法步；非法走法无法落下
- 将军提示、将杀判胜、逼和（无子可动且未被将军）判和
- 王车易位（长易位/短易位）、吃过路兵、兵到底线升变（后/车/象/马四选一弹窗）
- 子力不足自动和棋、五次重复局面与七十五回合自然限着自动和棋
- 三次重复局面、五十回合规则可点「提和」主张和棋；双人模式另支持协议和棋
- 「认输」结束对局；「悔棋」人机模式一次撤销双方两步、双人模式撤销一步

### 界面与操作
- 点击己方棋子选中（高亮合法落点：圆点=可移动，圆环=可吃子），再点目标格落子
- 右侧面板：行棋状态、双方损失棋子与子力对比、代数记谱棋谱（如 Nf3、O-O、exd5、Qh4#）
- 新对局 / 悔棋 / 提和 / 认输 / 返回主菜单

### AI 说明
内置 AI 为 Negamax + Alpha-Beta 剪枝搜索，结合子力价值与位置价值表：
- 简单：搜索 1 层，近优走法带随机性，适合新手
- 中等：搜索 2 层
- 困难：搜索 3 层（纯 Python 计算，复杂局面思考可能需数秒，属正常现象）

## 文件说明
- `chess_app.py`：程序全部源码（界面 + AI，单文件）
- `tests_logic.py`：规则与 AI 的无头逻辑测试（13 项）
- `smoke_gui.py`：界面自动化冒烟测试
- `dist\ChessGame.exe`：打包好的可执行程序
